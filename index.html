🕹 shadPS4 Web

PlayStation 4 emulator, compiled to WebAssembly

shadPS4 upstream· backend· frontend· PROJECT.md
What this does today: upstream shadPS4 (loader, linker, memory manager, ~200 HLE system libraries) runs in your browser, and the game's x86-64 code runs in an x86-64 interpreter. With WebGPU, what the game draws with the PS4 GPU is rendered too: its shaders are recompiled to WGSL and its draws and compute dispatches run on your GPU. Expect it to be very slow (the CPU side is interpreted), and some GPU features (geometry/tessellation stages, MSAA) are missing. Needs Chrome/Edge 133+ (wasm64 + SharedArrayBuffer). The game folder must be an extracted dump (e.g. from a fake PKG via tools/extract_pkg.py in the backend repo); files are read locally and never uploaded.
